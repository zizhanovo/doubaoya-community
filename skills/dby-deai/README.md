# 去 AI 味 / dby-deai

> 都爆鸭社区出品 · 纯本地工具 · 零网络调用 · 不需要 API Key

---

## 简介

把一段已经写好的中文里「一眼就是 AI 写的」地方**逐句指出来**。输入不限公众号——微信、小红书、
知乎、周报、方案、邮件都行。

**默认只出体检报告，不改稿。** 要改才改，且逐条附「改了什么」。

## 三档终态

| 用户在说 | 档位 | 交付物 |
|---|---|---|
| 这篇是不是有 AI 味 / 帮我看看 | **体检** | 哪一句、属于哪一族、改不改 |
| 帮我改掉 / 去一下 AI 味 | **改写** | 改后全文 + 逐条改动清单 |
| 改完还是没人味 | **加人味** | 先向你索料，你不给料就停 |

## 它和别的去 AI 味工具不一样在哪

- **不给 AI 率分数**。老舍《林海》被检测判 99.9% AI，OpenAI 自家分类器因真阳性率仅 26% 下架——
  分数会把注意力从「哪一句该改」引到「数字降没降」。本包只给位置和密度。
- **有豁免层**。判据清单每一族都带「什么不算」：真人也说「首先」，说明书本来就该整齐，
  公关稿的公文腔是体裁要求。报告里必须有「可以不改」那一栏。
- **看聚簇不看孤证**。单个词命中不报，同族反复出现或多族挤在一段才报。
- **不装人**。同义词随机替换、故意加错别字、故意写病句——一律不做，那三样只会把文写烂。
- **删和建分开**。删完套话得到的是无菌水；「人味」来自你的真实经历，模型自己填就是编造，
  所以加人味那一档**必须你供料**。

## 用法

```bash
python3 scripts/deai.py 稿件.md          # 体检报告
cat 稿件.md | python3 scripts/deai.py -  # 从 stdin 读
python3 scripts/deai.py 稿件.md --json   # 机器读
python3 scripts/deai.py --selfcheck      # 离线自检
```

脚本定位这些：套话连接词、公文腔、通胀大词、「不是A而是B」否定式对比、三段式并列、虚假范围、
连续同长句、公式化开头、结尾升华、破折号与加粗密度、数字与第一人称密度。

判断该不该改，交给 agent 对着 `references/病灶清单.md` 逐条过。

## 五条红线

1. 不帮删除 / 篡改 / 隐匿 AI 标识与声明——《人工智能生成合成内容标识办法》第 10 条禁止为此提供工具或服务。
2. 不承诺过检测器、不报 AI 率、不给总评分。
3. 学位论文 / 课程作业 / 投稿查 AIGC 的降重需求，不服务。
4. 批量洗稿、AI 托管账号，不服务。
5. 改文风不改事实；交付时提示按平台要求主动声明 AI 参与——**去 AI 味 ≠ 否认 AI 参与**。

## 一句话把事说清

**「有 AI 味」本身不违规，「冒充人写 + 低质批量」才违规。** 六大平台（微信 / 小红书 / 知乎 / 抖音 /
B站 / 头条）都要求主动声明 AI 生成，不标注的典型后果是限流或平台代打标；删封针对的是低质批量与造假。
所以把文风改好和主动声明，是要一起做的两件事。

平台口径与法规速查见 `references/平台标注.md`（2026-08-31 快照，会过时）。
