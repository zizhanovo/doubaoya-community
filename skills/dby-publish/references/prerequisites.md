# 前置条件（分层：不是每一步都要绑公众号）

> 想知道「我这一步到底要不要凭证 / 要不要绑号」时读它。

统一前置：**Node ≥ 22**，经 `dby` 命令运行，零外部依赖。除此之外**按你要做的事分层**：

| 想做的事 | 除 Node 外还需要 | 怎么跑 |
|---|---|---|
| 抓一篇**公开**文章做排版研究 | 公网（**不要凭证**） | `dby wechat fetch-article --url … --out ref.html` |
| md → 公众号内联样式 HTML（看排版效果 / 试主题） | 凭证（渲染免费） | `dby preview --file a.md [--theme <id> \| --theme-file t.json]` |
| 用你在 doubaoya.com 设置的**默认排版**渲染 | 凭证 | 不写 `--theme` 即可（渲染在平台做，主题也在平台套；失败中止、没有本地回退） |
| **只渲染拿在线预览链接**（`--render-only`，**不绑号也行**） | 凭证 | `dby wechat pipeline --md a.md --title "标题" --render-only` |
| **彩排**（`--dry-run`） | **凭证 + 已在 doubaoya.com 绑定公众号** | `dby wechat pipeline --md a.md --title "标题" --dry-run` |
| 本地图预上传 / 存草稿 | 同上（**存草稿花钱**，失败自动退回） | `dby wechat pipeline … --confirm`、`dby wechat publish … --confirm` |
| 封面 / 配图 | 用户明确要图时走 `dby-image`，或用户自备 | 封面喂 `--cover`、配图以 `<img src>` 落进正文 |

没有凭证时命令退出码 4 → 请用户跑 `dby login`；离线退出码 5。
1.x 包里的本机渲染器在已装用户那里仍可用，支持到 3.0.0；2.x 起不再随包提供。

> ⚠️ **`--dry-run` 不是免凭证预览，也不是免绑号预览**。它虽然什么都不发，但 whoami 校验账号
> 与草稿前置检查都排在它**前面**：没有凭证会停在「本地没有可用的 key」，有凭证但没绑号会停在
> 「目标账号没有已绑定的公众号」。
> 🔴 **这是刻意的**：`--dry-run` 的语义是「发布前彩排」，它**故意**包含账号校验与前置检查
> ——那正是它的价值（发布前确认目标账号没搞错）。
>
> **有凭证、还没绑号、只想先看这篇排出来什么样** → 用 **`--render-only`**：跳过草稿前置检查，
> 渲染完直接给你 `doubaoya.com` 的在线预览链接，全程不碰公众号、不写任何用户资产。
> 或用 `dby preview` 在本地落一份 375px 手机宽预览页。

绑好号、配好凭证之后，发布前先跑一次 `--dry-run`，确认身份上下文、目标账号、公众号、本地图扫描都对，再正式存草稿。
