# 公众号四类图的骨架

L3。入口在 [`prompt-ladder.md`](prompt-ladder.md)。只放本平台真正会用到的四类——
不是通用图库（Tattoo、游戏 HUD、等距视图那些对做公众号的人没用）。

用法：挑一个骨架 → 填 `{{}}` → 不满意再按 [`axes.md`](axes.md) 补**一个**维度。

---

## 一、公众号封面

**下游会被裁两次。** 消息列表按 **2.35:1** 裁，转发卡片与主页按 **1:1** 裁——
同一张图两种裁法，所以**关键内容必须落在中央的水平带里**。

```
比例：宽幅横版，16:9 比例
用途：公众号文章封面
主体：{{主体，一个就够，别堆}}
情境：{{极简情境或纯色背景}}
风格：{{扁平插画 / 杂志摄影感 / 手绘}}，画面干净
色彩：主色 {{品牌主色}}，背景低饱和，整体不超过三种颜色
构图：主体集中在画面中央的水平带内，上下留出大片干净背景；
      {{左侧 / 右侧}}留出空白区域用于叠加标题
排除：不要水印、不要边框、不要复杂细节
```

🔴 **「比例」那一行不能省。** `size` 参数无效，不写比例就会拿到 1254×1254 正方形，
再被按 2.35:1 裁掉上下大半——正好把你精心安排的主体切两刀。

🔴 **上下必须留白**——那两条边会被裁掉。主体顶到边等于被切头切脚。

### 要不要把标题画进图里

**可以，而且中文渲染实测可靠**（见 [`axes.md` 文字](axes.md#文字)，两次难例全对）。
想直接出带标题的封面，在骨架里加一行：

```
文字：主标题「{{标题}}」，粗黑体，{{颜色}}，位于{{位置}}；
      文字必须笔画准确、无错字、无多余字符
```

**但文案没定稿时别这么做**——标题改一个字就要重新出图重新花钱。
定稿了再画进去；没定稿就留白，排版时叠。

## 二、文章内插图

作用是**给读者一个喘气的地方**，不是承载信息。

```
用途：公众号文章内插图
主体：{{这一段在讲的那个东西的具象化}}
风格：扁平插画，线条简洁，与全文其他插图同一套风格
色彩：主色 {{品牌主色}}，整体清淡，不要抢正文
构图：留白充足，主体居中
排除：不要文字、不要水印、不要复杂背景
```

不写比例即可——默认正方形，插图用正方最省事。

**一篇文章里所有插图用同一套变量骨架**（见 `prompt-ladder.md` 最后一节），
否则读者会觉得图是东拼西凑来的。

## 三、账号主视觉 / IP 形象

出现频率低但影响大——它会被反复用。

```
比例：正方形
用途：账号主视觉 / IP 形象，会被长期反复使用
主体：{{IP 形象的具体描述，来自 IP 档案}}
姿态：{{正面站立 / 半身 / 侧面}}，表情 {{……}}
风格：{{风格}}，可爱但不幼稚，适合作为长期视觉符号
色彩：主色 {{品牌主色}}，配色不超过三种
构图：主体居中，纯色背景，四周留足边距
排除：不要文字、不要复杂场景、不要多个角色
```

🔴 IP 形象的所有特征（配色、造型、标志性元素）**必须来自 IP 档案**（正文红线四）。
档案里没有就先去 `dby-charter` 把人设立起来。
**这个形象一旦发出去就会被反复复用，编错的成本比一张图大得多。**

## 四、信息图 / 结构示意

用来讲清一个流程或对比。

```
比例：{{宽幅横版 16:9 / 竖版 9:16，看放在哪}}
用途：信息图，向读者解释 {{要讲清的那件事}}
主体：一张{{流程 / 对比 / 层级}}示意图，共 {{N}} 个模块
风格：扁平几何，粗描边，图标化
色彩：主色 {{品牌主色}}，模块之间用同色系深浅区分
构图：{{横向排列 / 纵向排列 / 网格}}，模块之间留清晰间距
文字：每个模块的标签分别是「{{标签1}}」「{{标签2}}」……，
      文字必须笔画准确、无错字
排除：不要装饰性元素
```

> 写明「用途：信息图」这一句是有用的——OpenAI 指南指出，
> 声明用途能让模型自己切到对的精细度档位。

## 五、什么时候不该用生图

诚实的一节。**每次调用都计费**，先判断这张图是不是真的需要生成：

| 情况 | 更好的做法 |
|---|---|
| 需要真实产品照 | 用真照片——生图会编出不存在的产品细节，而那属于「事实不许编造」 |
| 需要真实人物 | 别生成，肖像风险 + 不像 |
| 需要精确数据图表 | 用图表工具，模型画的坐标轴与数值不可信 |
| 只是要一张占位图 | 纯色块就行，别花钱 |
| 文案还没定稿但想连标题一起出 | 先留白，定稿了再出带字版 |
