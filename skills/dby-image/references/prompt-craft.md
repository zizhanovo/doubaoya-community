# 提示词工程：把「我想要那种感觉」变成能复现的 prompt

按需加载。正文只放出错时来不及读的红线，这份是**动手前想读才读**的。

---

## 一、三档写法：先问清要哪一档

同一个需求可以写成三种密度的提示词。**别默认写最长的那档**——
过度约束会让模型放不开，而用户往往只是要个草图。

### 极简档（探索用，先看方向对不对）

一句话，只给主体 + 风格：

```
一只戴耳机的卡通鸭子在写稿，扁平插画风
```

用在：用户还没想清楚、要先出两三张看方向。

### 平衡档（默认，绝大多数情况用这档）

**主体 + 动作/情境 + 风格 + 色调 + 背景 + 排除项**，一句话到三句话：

```
一只戴耳机的卡通鸭子坐在书桌前写稿，侧面视角；
扁平插画风，暖色调（米黄与橙），背景是干净的纯色；
不要文字，不要边框。
```

**「不要什么」和「要什么」一样重要**——尤其是「不要文字」：
模型很爱往图里塞看不懂的伪文字，而那是公众号配图最常见的返工原因。

### 高级结构化档（要复现、要成系列时用）

分块写，每块一行，便于逐块调整而不重写整段：

```
主体：一只戴耳机的卡通鸭子，坐姿，侧面 3/4 视角
情境：木质书桌，桌上一台笔记本电脑与一杯咖啡
风格：扁平插画，粗描边，轻微颗粒质感
色彩：主色 #FF8708，辅色米黄与深棕，低饱和背景
构图：主体居中偏左，右侧留白
光线：柔和顶光，无强阴影
排除：文字、水印、边框、人手
```

用在：要出一组风格统一的图（一个号的固定视觉语言）。

## 二、`{{变量}}` 模板：出系列图时保持一致

把「每张都一样的部分」写死，把「每张不同的部分」留成变量：

```
主体：{{主体}}
情境：{{情境}}
风格：扁平插画，粗描边，轻微颗粒质感
色彩：主色 {{品牌主色}}，辅色米黄与深棕
构图：主体居中偏左，右侧留白
排除：文字、水印、边框
```

然后每张只填两三个变量。**这是「让一个号的图看起来是同一个号的」最省力的办法**——
比每次重写整段提示词稳定得多。

🔴 `{{品牌主色}}` 这类**必须从 IP 档案取真值**（正文红线四），
档案里没有就问用户，别自己填一个。

## 三、图像反推：给一张图，还原出可复现的提示词

**这一步不调任何接口、不花钱**——用你自己的视觉能力看图，然后按下面七项逐条描述。

用户说「我要这种感觉」时，先做这一步，把「感觉」变成文字，跟用户确认，再出图。

### 七项清单

1. **主体**：画面里最重要的那个东西是什么，什么姿态、什么视角
2. **情境**：它在哪儿，周围有什么
3. **风格**：写实 / 扁平插画 / 水彩 / 像素 / 3D 渲染 / 线稿 / 国风水墨……
4. **色彩**：主色、辅色、整体饱和度高还是低、冷调还是暖调
5. **构图**：主体在画面什么位置，留白在哪，是不是对称
6. **光线**：光从哪来，硬光还是柔光，有没有明显阴影
7. **质感**：有没有颗粒、噪点、笔触、纸纹

### 反推时的两条纪律

- **只描述你真的看见的东西。** 看不出用的什么软件、什么模型，就别写「Midjourney 风格」——
  那是猜的，而且对出图没帮助。
- **反推结果要给用户确认再用。** 你看到的重点和用户想要的重点常常不是同一个，
  确认一次比出错三次便宜。

## 四、常见返工原因（写提示词时顺手避掉）

| 现象 | 原因 | 提示词里加什么 |
|---|---|---|
| 图里出现看不懂的伪文字 | 没排除文字 | `不要文字，不要水印` |
| 主体被裁掉 | 没考虑下游裁切 | `主体居中，四周留出安全边距` |
| 一组图风格不统一 | 每次重写提示词 | 用第二节的 `{{变量}}` 模板 |
| 颜色和品牌对不上 | 用了「暖色」这类模糊词 | 直接给十六进制色值 |
| 画面太满、没地方放标题 | 没要求留白 | `左侧/上方留出干净区域用于叠加标题` |

---

## 五、和尺寸有关的一件事

`size` 是建议不是契约（正文红线六）。所以**需要留白给标题时，靠提示词要留白，
而不是靠尺寸**——尺寸可能不是你要的那个，但「左侧留出干净区域」这条模型会听。
