# 风格参考

**这是一份菜单，不是一份规定。**

用户没说风格时，**别从这儿挑一个替他定**——给他两三个选项让他挑。
用户说了风格就按他说的，这份表只在他想看看有什么选择时才用。

每条给的是**可以直接放进提示词的片段**。片段之外的东西（配色、主体、背景）
仍然由用户或他的 IP 档案决定。

---

## 插画类

| 风格 | 提示词片段 | 适合 |
|---|---|---|
| **扁平插画** | `扁平插画风，简洁色块，无渐变` | 干货、流程、通用配图 |
| **粗描边卡通** | `粗描边卡通风，线条厚重，色块明快` | 轻松话题、IP 形象 |
| **线稿** | `单线线稿，只有轮廓线，无填色` | 极简、logo 感、可叠色 |
| **手绘水彩** | `水彩手绘，笔触与晕染可见，纸张纹理` | 生活、情感、慢节奏内容 |
| **国风水墨** | `水墨写意，留白大，墨色浓淡变化` | 文化、传统、深度长文 |
| **等距 2.5D** | `等距视角插画，2.5D，轻微立体感` | 产品说明、系统结构 |
| **像素画** | `像素画风格，低分辨率块状，复古配色` | 科技怀旧、游戏话题 |
| **拼贴** | `剪纸拼贴风，纸质边缘，层叠错位` | 潮流、创意、活泼选题 |

## 写实类

| 风格 | 提示词片段 | 适合 |
|---|---|---|
| **杂志摄影** | `杂志摄影感，自然光，浅景深，真实材质` | 生活方式、产品、人物 |
| **胶片质感** | `35mm 胶片，细微颗粒，自然色彩偏移` | 叙事、回忆、真实感 |
| **静物摆拍** | `俯拍静物摆拍，柔和顶光，干净台面` | 好物、工具、清单类 |
| **纪实抓拍** | `抓拍瞬间，未摆拍，环境光` | 故事、访谈、现场感 |

## 怎么挑

**别按「哪个好看」挑，按「这个号是什么调性」挑。**

- 用户的 **IP 档案**里有人设与品牌调性 → 优先照它
- 档案是空的 → 给两三个选项让用户挑，**顺便提醒他这类选择存进档案后就不用每次重挑**
- 一个号一旦定了风格就**别随篇换**——读者认的是那套视觉，换了就等于换了个号

---

## 一组图要统一

同一篇文章的插图、同一个号的封面，风格片段要**逐字一致**。
做法见 [`prompt-ladder.md`](prompt-ladder.md) 最后一节的变量骨架：
把风格片段写死在骨架里，每张只换主体。

---

## 组合是可以的

风格片段可以叠，但**别超过两个**——三个以上模型会做加权平均，
出来的东西哪个都不像。

```
扁平插画风，简洁色块      +  轻微颗粒质感        ✅ 两个，方向一致
水彩手绘  +  像素画  +  杂志摄影感                🔴 三个且互相打架
```

---

## 这份表没有的

用户想要的风格不在表里，**照他的原话写进提示词就行**——
这份表是给「不知道有什么选择」的人用的，不是白名单。
