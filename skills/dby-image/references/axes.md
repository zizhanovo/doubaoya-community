# 六个维度的具体写法

**只在 L2 需要时读，而且只读你要补的那一节。**
入口与「症状 → 补哪个维度」的对照在 [`prompt-ladder.md`](prompt-ladder.md)。

规则不变：**一次只加一个维度**。

---

## 构图

控制的是：主体在画面什么位置、镜头离多远、从什么角度看、留白在哪。

三件事分开写，别混成一句：

| 要控制 | 写法 | 可选值 |
|---|---|---|
| **取景** | `远景 / 中景 / 近景 / 特写` | 决定主体占画面多大 |
| **视角** | `平视 / 俯视 / 仰视 / 正上方俯拍` | 决定情绪，仰视显强势、俯视显全局 |
| **位置** | `主体居中偏左，右侧留出空白` | **要留白给标题时必写这一行** |

```
构图：中景，平视；主体居中偏左，右侧三分之一留出干净空白用于叠加标题
```

> OpenAI 指南特别提到：**版面位置要说就说死**——「logo 放右上角」「主体居中、左侧留负空间」
> 这种明确指令比「构图好看」有用得多。

---

## 光线

**这是「图看起来平不平」的第一决定因素**，也是最容易被忽略的一个维度。

光线只写「柔和的光」没用，模型只能猜。要给**三件事**：

| 要素 | 写法示例 |
|---|---|
| **方向** | `侧光从左前方打来` / `顶光` / `逆光` / `窗光从右侧进入` |
| **性质** | `柔和漫射` / `硬光，边缘锐利的阴影` / `无明显阴影` |
| **氛围** | `清晨冷调` / `黄昏暖光` / `阴天灰调` / `高对比戏剧光` |

```
光线：侧光从左前方打来，柔和漫射，阴影很淡；整体暖调
```

常用组合速查：

| 想要的感觉 | 光线怎么写 |
|---|---|
| 干净、商务、可信 | `顶部柔和漫射光，阴影极淡，无强反差` |
| 温暖、生活感 | `窗光从侧面进入，暖调，柔和长影` |
| 戏剧、有张力 | `单侧硬光，高对比，大面积暗部` |
| 通透、清新 | `明亮均匀的自然光，高调，几乎无阴影` |

## 色彩

**别用「暖色调」这种模糊词——直接给色值。**

```
色彩：主色 #FF8708（橙），辅色米白与深棕；背景低饱和，整体不超过三种颜色
```

三件事值得写死：

- **主色**（十六进制最准）
- **色彩数量上限**——`整体不超过三种颜色` 这一句能显著减少画面杂乱
- **饱和度倾向**——`低饱和` / `高饱和` / `接近黑白只留一处彩色`

🔴 品牌色**必须从 IP 档案取**（正文「图里的事实同样不许编造」那条）。档案没有就问用户。

## 文字

### ✅ 实测结论：**你点名的**中文是可靠的

2026-08-21 实测，**含长标题 + 副标题 + 阿拉伯数字的难例，全部笔画准确、无错字**：

| 测的内容 | 结果 |
|---|---|
| 「写作的第一性原理」 | ✅ 全对 |
| 主标题「公众号写作的 10 个反直觉真相」+ 副标题「第 3 条我踩了三年才明白」 | ✅ 全对，层级、字重、位置都按要求 |
| 「深夜写稿指南」（同日第三次复测，两张样本） | ✅ 两张都逐字准确 |

⚠️ 这条**推翻了「模型写不好中文、标题一律后期叠加」的旧经验**——那是对别的模型的印象。
本包的结论以对**这个后端**的实测为准。

### 🔴 但这个结论只覆盖「提示词点名的文字」

**模型自己往画面里加的字，默认不可靠——尤其是密集小字。**

实测：标题类的点名文字两张全对；而模型**自行添加**的十余处装饰性文字
（书脊、便签、笔记正文这类**小字密集排布**的）**大量是乱码笔画**，放大就能看出来。

⚠️ 但别把这条推太远：另一张图里模型自行加的木牌英文 "Happy Winter!" 一字不差。
⇒ 真正的判据不是「点没点名」，而是**字小不小、密不密**：
孤立的大字（招牌、标语）多半没问题，成段的小字多半是乱码。
⇒ 两种情况都得看——所以规则仍然是「整张扫一遍」，只是心里有个优先级。

危险在于它不报错、缩略图上也看不出来：你只点名了标题，验收时也就只盯标题，
判「文字全对」交付出去；而用户发出去之后，读者盯着看的偏偏是那些小字。
这是 [`visual-review.md`](visual-review.md) 里命中率最高的一条客观缺陷。

⇒ 不想要多余文字时，在提示词里说死：`除标题外，画面中不出现任何其他文字`。
但注意这属于**排除项**——是出了问题之后才加的补丁，不要预防性地默认带上
（[`prompt-ladder.md`](prompt-ladder.md) L1）。

### 怎么写

四件事：**字面文字加引号 + 字重 + 颜色 + 位置**。

```
主标题「写作的第一性原理」，粗黑体，深棕色，居中偏上
副标题「第 3 条我踩了三年才明白」，小一号，灰褐色，在主标题正下方
所有文字必须笔画准确、无错字、无多余字符
```

- **字面文字一定要加引号**（OpenAI 指南的明确建议），模型才知道这是要照抄的字
- 品牌名、生僻字这类容易写错的，可以**逐字拆开写一遍**加强准确率
- 最后那句「无错字、无多余字符」值得常带——模型有时会自己加装饰性字符

### 什么时候仍然该后期叠加

- 文案还没定稿（图不能跟着改一次生成一次，那是重复花钱）
- 需要精确的字体、字号、行距（那属于排版，不属于生图）
- 同一张底图要出多个标题版本

## 质感

解决的是「看起来太干净、太 AI」。

```
质感：轻微胶片颗粒，纸张纹理，笔触可见
```

按媒介选：

| 媒介 | 加什么 |
|---|---|
| 照片感 | `细微胶片颗粒`、`真实皮肤纹理与毛孔`、`布料磨损痕迹` |
| 插画 | `可见笔触`、`粗描边`、`纸纹` |
| 3D | `柔和次表面散射`、`微磨砂材质` |

> OpenAI 指南的说法：要真实感就**明确要求"不完美"**——毛孔、皱纹、磨损、日常痕迹，
> 并且**避开**「精修」「摆拍」「影棚级」这类暗示打磨的词。

## 相机语言

**只在要写实照片感时才用。** 插画类图加这些没意义。

```
相机：35mm 胶片质感，50mm 镜头，中近景，平视；浅景深，自然色彩
```

四个旋钮：

| 旋钮 | 例 | 影响 |
|---|---|---|
| **镜头** | `35mm` / `50mm` / `85mm` / `广角` | 50mm 接近人眼，85mm 压缩背景显专业 |
| **景深** | `浅景深，背景虚化` / `全画面清晰` | 浅景深突出主体 |
| **胶片/数码** | `35mm 胶片质感，自然色彩` | 胶片感能显著去掉"AI 味" |
| **快门感** | `抓拍，未摆拍` | 让画面不那么僵 |

🔴 **别写 `8K`、`ultra-detailed`、`masterpiece`。** OpenAI 指南直说：
对 gpt-image 这类模型，**具体的相机与光线描述比这些泛泛的质量形容词可靠得多**。
那些词是上一代模型时期的习惯，留着只是占位置。
