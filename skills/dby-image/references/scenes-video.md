# 短视频封面（抖音 / 视频号 / 快手）

L3。入口在 [`prompt-ladder.md`](prompt-ladder.md)。

短视频封面和图文封面最大的不同：**它会被播放器的 UI 盖住一部分**，
而且**在主页网格里只露中间一块**。所以关键内容的位置比画面本身更要紧。

---

## 比例：竖版

三家都以竖版为主。**给比例，不给像素**——我们的 `size` 参数完全无效（正文红线六），
而且各家教程给的像素值本身就打架。

```
比例：竖版，3:4 比例
```

⚠️ **各源不一致的地方，如实说**：抖音多见 3:4 与 9:16 两种说法；
视频号有资料说官方竖版是 6:7。**没有一个我能确认为权威的单一答案。**
好在下面这条更要紧、也更稳：**关键内容压在画面中央，四周都留余量**——
不管最终按哪个比例裁，中间那块都在。

---

## 🔴 两处会被吃掉的区域

这是短视频封面和图文封面最本质的差别。

### ① 信息流播放时

- **底部**：文案、账号名、音乐信息压在这里
- **右侧**：点赞 / 评论 / 分享 / 头像这一竖排按钮压在这里

⇒ **标题不要放底部，主体不要贴右边。**

### ② 主页网格（九宫格）时

只显示封面**中间的一块**，上下会被裁掉。

⇒ **主标题和主体必须在垂直中段。**

两条合起来就是一句话：**把该看见的东西放进画面正中央那一块，四周全当会被吃掉。**

---

## 骨架

```
比例：竖版，3:4 比例
用途：短视频封面，会在信息流与主页网格两种场景下展示
构图：所有关键内容集中在画面中央区域；
      底部三分之一与右侧边缘不放任何关键信息（会被播放器 UI 遮住）
文字：主标题「{{标题，≤10 字}}」，超大号，位于画面垂直中央偏上
{{用户想要的画面内容}}
```

**这里的每一行都是客观约束**，不是审美：比例因为 `size` 无效、
构图因为两处会被吃掉、标题短因为用户是滑过去的。
风格与配色不在骨架里——挑 [`styles.md`](styles.md) 或看 IP 档案。

---

## 标题要更短

图文封面还能放十来个字，短视频封面**十个字就到顶**。

原因很实在：用户是**滑**过去的，不是**读**过去的。
一屏停留不到一秒，长标题等于没标题。

---

## 一稿多发时怎么办

同一条内容要发抖音 + 视频号 + 快手时，**不用出三张图**——三家都是竖版、
安全区逻辑一致，一张按上面骨架做的图三家通用。

但**别把它拿去发小红书**：小红书是 3:4 瀑布流、大字报范式，
关键内容位置和这里不一样（见 [`scenes-xiaohongshu.md`](scenes-xiaohongshu.md)）。
更别拿去当公众号封面——那是 2.35:1 横版（见 [`scenes-wechat.md`](scenes-wechat.md)）。

---

## 真人出镜的号

如果这个号是真人出镜，封面通常用视频截帧而不是生成图——
**生成的人脸不是本人，会破坏账号的人格识别**。

这种情况下生图能做的是：给截帧配一个**纯图形的标题底板**
（比如一条色块 + 大字），再由排版工具叠上去。

```
比例：竖版，3:4 比例
用途：短视频封面的标题底板，将叠在真人截帧之上
主体：一条 {{颜色}} 的半透明色块，位于画面垂直中央偏上，横贯左右
文字：色块上写「{{标题}}」，超大号粗黑体，{{文字色}}
背景：完全透明或纯色，除色块与文字外无其他元素
排除：不要人物、不要插图、不要水印、不要边框
```

🔴 **不要生成"看起来像博主本人"的人物**——那既不像，也涉及肖像问题，
而且违反「事实不许编造」那条红线（正文红线四）：这个号的人是谁，不是可以生成的东西。
