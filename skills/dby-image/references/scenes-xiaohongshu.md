# 小红书封面与配图

L3。入口在 [`prompt-ladder.md`](prompt-ladder.md)。

小红书的视觉语言和公众号**几乎相反**——公众号封面要干净留白给标题，
小红书封面**标题本身就是主视觉**。别把公众号那套搬过来。

---

## 比例：竖版 3:4

官方给三种：竖屏 **3:4**、正方 **1:1**、横屏 **4:3**。
**绝大多数情况用 3:4**——瀑布流里占屏面积最大，同样一屏你的卡片更显眼。
（这是客观的展示规律，不是审美规定；用户要 1:1 或 4:3 就按他的。）

```
比例：竖版，3:4 比例
```

> 📌 为什么这里只给比例不给像素：我们的 `size` 参数**完全无效**（正文「比例只能写进 prompt」那条），
> 比例只能靠提示词。而各家教程给的像素值本身就互相打架
> （1080×1440 / 1242×1660 / 900×1200 都有人说是"官方"），
> 好在**它们全都是 3:4**——所以比例是可信的那一层，像素不是。
> 真要精确像素，拿到图之后自己缩。

## 一、大字报封面（最主流，先默认用这个）

小红书封面的核心范式：**标题占据画面主体**，图只是底衬。
用户在瀑布流里是"读封面"，不是"看封面"。

```
比例：竖版，3:4 比例
用途：小红书笔记封面
文字：主标题「{{标题}}」，超大号，占据画面上半部分
{{用户想要的画面内容}}
```

**客观约束只有两条**：3:4（`size` 无效只能写 prompt）、
以及瀑布流里卡片很小所以**标题要大要短**（≤12 字左右）。
其余是选择不是规定——风格挑 [`styles.md`](styles.md)，配色看 IP 档案。

🔴 **标题一定要短。** 瀑布流里卡片很小，超过十来个字就糊成一片。
中文渲染实测可靠（见 [`axes.md` 文字](axes.md#文字)），所以标题可以直接画进图里。

### 高饱和是有原因的

小红书的推荐流里同屏有十几张卡片在抢注意力。低饱和的图**不是显得高级，是显得没有**。
多个爆款拆解都指向同一件事：**高饱和 + 强对比色**在这个场景里赢。

（做**你自己的号**时，饱和度要服从 IP 档案里的品牌调性——先看档案再决定，
别拿平台通用规律覆盖掉这个号自己的视觉识别。）

---

## 二、对比型封面（前后 / 左右）

拆解爆款时反复出现的一种：**用反差本身当钩子**。

```
比例：竖版，3:4 比例
用途：小红书笔记封面，左右对比
构图：画面竖直分成左右两半，中间一条清晰分界；
      左半边是 {{改变前的状态}}，右半边是 {{改变后的状态}}
文字：左上角小标签「{{Before}}」，右上角小标签「{{After}}」；
      底部一行主标题「{{标题}}」
两边的视觉反差要明显
```

**反差越强越好**——这类封面的全部价值就在那一眼的落差。

---

## 三、清单 / 合集型封面

适合"N 个方法""必看清单"这类内容。

```
比例：竖版，3:4 比例
用途：小红书笔记封面，清单合集
文字：顶部主标题「{{N}} 个 {{主题}}」，超大号；
      下方 {{N}} 行短条目，每行一个短词，字号小于标题
构图：条目纵向等距排列
```

⚠️ 条目控制在 **5 条以内**，多了在小卡片上看不清。

---

## 四、九宫格 / 多图笔记的配图

小红书一篇笔记可以放多张图。**同一篇里的图必须是一套**，否则翻页时很乱。

做法：用 [`prompt-ladder.md`](prompt-ladder.md) 最后一节的**变量骨架**，
把风格、色彩、构图写死，每张只换主体。

```
比例：竖版，3:4 比例
{{固定的风格片段 —— 从 styles.md 挑一次，之后每张逐字照抄}}
{{固定的构图与配色 —— 来自 IP 档案}}
{{每张唯一变的那一项}}
```

---

## 五、账号整体感

小红书主页是**网格**——十几张封面同屏出现。单张好看没用，**一整屏得像一个人做的**。

所以：同一个号的封面固定住三样——**主色、字体风格、构图位置**，只换内容。
这也是变量骨架真正的价值所在。

🔴 主色必须来自 IP 档案（正文「图里的事实同样不许编造」那条）。档案里没有就先去 `dby-charter` 立人设。

---

## 六、这些别做

| 别做 | 为什么 |
|---|---|
| 把公众号封面直接拿来用 | 比例不对（2.35:1 vs 3:4），而且公众号那种留白风格在瀑布流里"没存在感" |
| 标题写十几个字 | 卡片小，糊成一片 |
| 低饱和"高级灰" | 同屏十几张卡片时看不见 |
| 文字压在主体脸上/关键物件上 | 多个拆解都提到「少遮挡」，尤其真人出镜类 |
| 每篇换一套视觉 | 主页网格会显得杂乱，账号没有识别度 |
