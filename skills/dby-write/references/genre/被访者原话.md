# 体裁手艺 · 被访者原话（人物访谈 / 专访）

> 第 3 步声明「素材形态 = 被访者原话」时，第 5 步列提纲前读这份。
> ⚠️ 本形态属 **A 组**：锚点硬要求与缺锚点的处置阶梯在 SKILL.md 第 4 步与 `materials.md`，
> 本份不重复。杜撰现场对话的后果有实证：记者杜撰杨绛采访细节（"这些所谓的现场采访都是记者杜撰的"），被当事人识破并拒绝再配合——那是红线一的事，这里只讲拿到真素材后怎么写。

每条建议末尾标证据档：[实证]=真实已发布文章或完整写作系统；[业务]=新闻/写作业务论述（跨语境要迁移）；[经验]=运营者自述、无样本量。

## 这类文章长什么样

四种写作形式（军报新闻业务论述，按素材形态挑）[业务]：

1. **一问一答式**——最简单，读者看起来轻松；问答本身足够精彩时用。
2. **第三人称通讯式**——"把专访者回答的问题揉碎融合"，适合素材多而散、需要重组的。
3. **结合式**——答问与经历、事迹、观点结合，最灵活。
4. **第一人称独白式**——从头到尾是被访者自述（案例：《"吹灯兵"的情怀》，获当年中国新闻奖一等奖）；原话足够多、足够有个性时是上选。

- 结构惯例：大主题破成几个并列的小主题，素材按典型度分详略；"人物的经典语言及精彩的细节需要格外突出"。[业务]

## 动笔前必须有什么

（这四样也是第 4 步素材单对本形态的最低配置）

- **行为观察**："我们写一个人不能让记者自己出来……你要使用他自己表现出来的行为和他的语言"——勇敢/坚强这类标签由行为呈现，不由作者宣布（杜涌涛《写好人物的十四点提示》）。[业务]
- **个性化的原话**："能作为引语的必须是这个人说的具有个性化的话，只有他才会说这话……一定要短小精悍。"[业务]
- **至少一个周边视角**：杜涌涛的标准是"采访一个人物要采访二十个人，最少应该采访十个人"——公众号做不到这个量，但"只有本人一个信源"是明确的下限外；被访人"经常意识不到自己在别人心目中的印象"。[业务]
- **具体场景**：访谈发生的环境、动作、停顿——它们让引语可信。

## 开头与结尾

- 开头建议从人物身上真实长出来的一个细节或一句原话起笔，忌套模板——访谈的开头惯例恰恰是"没有惯例"，从人物特质出发。[业务]
- 结尾常见收法是把人物最有分量的一句原话放在最后，作者不再加评论。[经验]
- 🔴 第一人称边界（本体裁与「带转折的真实经历」最大的分野）：记者是**提问者与观察者，不是评论者**。杜涌涛的立场极硬："我个人非常不赞成。我们的报道时而也会有记者出来。出来我就会删掉的。"连"很诗意的话"也删——"新闻就是事实"。[业务]
- ⚠️ **采访姿态是行业内公开分歧，两说并存、不挑一种当铁律**：杜涌涛主张一律平视、解构名人神秘感；滕俊杰主张分对象——"采访普通人，有一点仰视"（给足尊重让人放松）、采访官员和艺术家平视、对流量明星"保持一种俯视"（以媒体立场审事）。按你的号的人设与对象自选。[业务]

## 写砸的样子

- **传声筒**："我们不要做被采访对象的传声筒"，"我最厌恶的是“他说”，“他说”，“他又说”"——大段转述加"他说"串联。[业务]
- **人物小传**："人物报道切忌写成人物小传"，"只是有文照录"——履历平铺，没有选择、没有细节权重。[业务]
- **仰视成追星**：滕俊杰批评的状态——"把自己变成了追星一族"，扭曲了媒体的格调与责任。[业务]
- **素材不足硬写本人**：《奥数天才的坠落之后》的教训——对本人的采访用得少，用学校老师同学的转述加作者观点填满，被当事人公开指认失真。素材偏科时，宁可缩小主题服从素材。[实证]
- 服从素材的正面样板：解放军报那次采访，对方开口说的与预设主题相反——记者从她的话里听出"我没有奉献什么"、两人结婚"完全是因为彼此相爱"，"于是，记者调整了报道思路"，改写成《"请你理解我的爱"》并获当年全国好新闻奖。[实证]

## 容易串到哪去

- 串到**带转折的真实经历**：写着写着"我"占了主位，被访者成了背景板。判据看引语密度与视角：主体是他的话和他的行为 → 本形态；主体是你的经历 → 改声明。
- 串到**可核实的具体事件**（观点文）：借访谈之名行评论之实——引语只是你论点的道具。想评论就按观点文写，别让被访者替你说话。
