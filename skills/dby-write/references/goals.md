# 第 3 步 · 读者与目标（涨粉 / 变现 / 常青 三种目标的结构差异 + 读者意识五阶段 + 变现文的 offer 表）

> 第 3 步定标题前读它。用户已明说目标且不是变现文时，只看第一张表那一行就够。

## 先写一行

```
本篇：目标 = 涨粉 | 变现 | 常青 ； 读者阶段 = 无意识 | 问题 | 方案 | 产品 | 最高 ； 人称语气 = （从 voiceSystemPrompt 抄）
```

这一行随提纲一起进上下文，第 5–8 步都照它写。

## 三种目标的结构差异

| | 涨粉文 | 变现文 | 常青文 |
|---|---|---|---|
| 选题 | 对齐已被推荐过的同题 10 万+，换成自己人群的角度；C 端公共议题 | 读者反复问、留言 / 私信里有原话的问题；先过「有人在搜吗」 | 语义核心 3 年内不变的题（方法 / 机制 / 原理），不写工具榜与热点评论 |
| 标题 | 人群词进标题；完整陈述句 + 好奇缺口 | 按读者阶段答那个阶段的问题（见下表） | 含「怎么做 / 是什么 / 为什么 / 最好的」类词与读者真会搜的关键词 |
| 长度 | 短、单点、易转 | 以成交为准，需要长就长 | 权威、完整，一篇顶六篇 |
| 骨架 | 一条可直接转述的实用价值 + 一句可引用的「显得有见识」的话 | 事实表 → 利益表 → offer 表；逐条回答买家会问的所有问题 | 问题链，可跳读；定期更新数据与案例 |
| 情绪 | 高唤起（敬畏 / 愤怒 / 焦虑 / 有趣）；低唤起（温馨 / 平静）转发少 | 「现在就在疼」的症状，不写未来风险 | 平实，靠完整性 |
| CTA | 文前一行定位 + 文末关注卡；留言区邀请表达认同（**留言可选，见第 8 步**） | 一次，放在价值之后；老客 / 新客两版；带购买方式必标「广告」 | 内链自己的相关常青文 |
| 复盘 | 引导关注人数（不是阅读量） | 转化 / 咨询 | 发布后仍在涨的阅读（搜一搜、看一看、文末推荐） |

🔴 **「标题」那一行就是第 3 步「缺口」项的依据** —— 涨粉写着「+ 好奇缺口」，
常青那格本来就没有缺口。所以缺口项只对涨粉/变现强制，是把这张表早就分好的差异接上去。
⚠️ 常青换的是入口（**靠搜索被找到**），不是不管点开率，所以「搜索适配」对它反而更重要。

## 读者意识五阶段（Schwartz）决定标题答什么

| 阶段 | 读者状态 | 标题 / 开头要答的问题 |
|---|---|---|
| 无意识 | 不觉得自己有这个问题 | 讲故事或立信念，先让他认出自己 |
| 问题意识 | 知道疼，不知道有解 | 戏剧化痛点，引出「一类解法」 |
| 方案意识 | 知道有几类解法，在比较 | 给证明和差异：为什么是这一类 / 这一种 |
| 产品意识 | 知道你的产品，还有顾虑 | 逐条去异议 |
| 最高意识 | 只等一个理由下单 | 只给 offer 与时间点 |

涨粉文与常青文读者多在前两阶；变现文写之前必须标清楚，标错阶段的文章「哪句都对但没人动」。

## 变现文：先出三张表，再写标题

写任何字之前，先填完这三张表（都来自素材单，红线一同样约束）：

```
事实表：产品 / 服务的每一个客观事实（是什么、多少、多久、谁做、怎么交付）
利益表：每条事实对这个读者意味着什么（他省下 / 得到 / 避免了什么）
offer 表：价格、赠品、保证、期限、名额、付款与退款方式  ← 先定它，offer 比文案重要十倍
反对意见清单：读者不买的每一个理由 → 提纲里哪一块回答它
```

提纲每一节对应一个买家疑问；写完拿反对意见清单逐条对，没被回答的补块。
老客只需「价值说到位 + 时间点」，新客需要证明与降低门槛，CTA 分两版。

**广告标识**：带购买方式（链接 / 二维码 / 店名 / 口令）的变现文，文首显著标「广告」——第 9 步硬拦，不是可选项。

## 素材形态六取值（SKILL.md 第 3 步声明用）

| 形态 | 手里有的 | 锚点组 |
|---|---|---|
| 可复现步骤 | 一套别人照做能跑通的操作 | B |
| 并列多项 | 互不依赖、能拆条罗列的多个项 | B |
| 可核实的具体事件 | 一件能指名道姓、能被查证的事 | B |
| 待解释的现象或机制 | 一个说得清、但多数人没想明白为什么的现象 | B |
| 带转折的真实经历 | 一段真发生过、有明确后果的事 | **A** |
| 被访者原话 | 采访得来的、只有他会那么说的话 | **A** |

**A 组要第一人称锚点，B 组不要**，它决定第 4 步缺素材时怎么处置。
⚠️ **「待解释的现象或机制」与「可核实的具体事件」的分界**：前者手里是**待拆解的机制**，
回答「它为什么会这样」（例：为什么公众号打开率集体下滑）；后者是**已成立的事实 + 一个立场**，
回答「我怎么判断它」（例：某平台宣布下架外链，我认为这是错的）。同一件事可以两写，看手里有的是哪样。
⚠️ 自陈可以谎报，由第 4 步素材单兜底（每条要编号与出处）；本步不试图防住。

## 为什么常青不强制缺口

> 为什么常青不强制缺口：实操教程的标题惯例本来就是平实描述。真实反例 ——
> 《开发将 Markdown 一键发布到微信公众号草稿工具的经验分享》（jimmysong.io，已发布），
> 零悬念零颠覆，而它正是这类文章该有的样子。硬套缺口只会让它伪装悬念，读者一眼识破。
