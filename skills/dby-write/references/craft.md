# 写作手艺速查（标题写法 / 提纲结构 / 正文手法）

> 第 3 步挑标题写法、第 4 步挑提纲结构、第 5 步落笔时读它。心里已经有形状就不必读。

## 标题的几种写法（第 3 步）

可组合的几种写法：关键词吸睛（对号入座 / 升维词 / 借势）、冲突反差、
提问式、悬念式、场景式、经验分享式、强调式。

## 四种提纲结构（第 4 步）

选一种结构，别混着来：

| 结构 | 形状 | 适合 |
|---|---|---|
| 问题-方案-行动 | 抛痛点 → 系统方案 → 引导行动 | 教程、方法论 |
| 故事-观点-延伸 | 真实故事降防御 → 引出观点 → 延伸到读者 | 个人经历、案例 |
| 热点-解读-预判 | 还原事件 → 独特解读 → 趋势预判 | 追热点（24h 内发） |
| 清单-深度-总结 | 全貌表格 → 逐项展开 → 行动清单 | 干货合集 |

## 正文手法与重点标记（第 5 步）

- **开头要缓**：此时读者信息最少，先铺垫。避免开头就上陌生概念或大段个人情绪。
- **结尾要硬**：此时读者信息量最大，给不了更多细节了。别玩花活，
  要求只有一条——**不使中心思想变形**。
- **衔接要净**：上一幕是上一幕，这一幕是这一幕。实在不行就用序号。
- **内容不够时不要扩写，去写细节**——但细节必须从范文样本或取数结果里取（红线一）。

**重点标记按规范的两档来用**（第 1 步拉到的那份里写着确切规则）：
`**加粗**` 标「这句话是重点」，每段 1~3 处，整段加粗等于没标；
`*…*` 标「这几个字要被眼睛扫到」，比加粗轻一档。
🔴 在中文稿里 `*…*` **不是斜体**——汉字没有真正的斜体字形，渲染器把它接管成了关键词记号。

## 结尾的行动号召（第 5 步）

**结尾的行动号召从档案里取**：`prep --json` 的 `products[].ctaScript`（每个产品各一条，
取匹配当前选题那个产品的）。背书 / 案例 / 内容资产**没有专属字段**：档案里叫什么取什么
（`persona`、`charter.positioning` / `charter.audience`、范文），没有就按红线一留【待补】，
**绝不自己编一个背书**。

## 摘要与留言（第 6 步）

两个最容易被忘的地方，流程化写作的价值就在这儿：

- **摘要**：订阅者在号内、分享到对话框都看得到，和标题同等重要——按「备用标题」写，别写成正文缩写。
- **留言**：作者给自己文章的第一条留言，既打破 0 留言的尴尬，更是**写作者对读者说的话**。
