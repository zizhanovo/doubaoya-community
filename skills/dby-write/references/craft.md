# 写作手艺速查（标题写法 / 提纲结构 / 正文手法 / 重写 / CTA / 摘要留言）

> 第 3 步挑标题写法、第 5 步挑提纲结构、第 6 步落笔、第 7 步重写时读它。心里已经有形状就不必读。

## 标题的几种写法（第 3 步）

可组合的几种写法：关键词吸睛（对号入座 / 升维词 / 借势）、冲突反差、
提问式、悬念式、场景式、经验分享式、强调式。

写完按 SKILL.md 第 3 步五项过。**缺口那一项看本篇目标** —— 涨粉/变现才强制。

- **目标 = 涨粉 / 变现**：「天然正确、人人已知」的标题（《成长比工资重要》）不算缺口，
  要改成有认知落差的写法。
- **目标 = 常青**：平实描述就是这类的正解，别硬套缺口。
  真实范例：《开发将 Markdown 一键发布到微信公众号草稿工具的经验分享》（jimmysong.io，已发布）——
  零悬念零颠覆，读者靠「这正是我要找的东西」点进来，不靠好奇。

## 四种提纲结构（第 5 步）

选一种结构，别混着来：

| 结构 | 形状 | 适合 |
|---|---|---|
| 问题-方案-行动 | 抛痛点 → 系统方案 → 引导行动 | 教程、方法论 |
| 故事-观点-延伸 | 真实故事降防御 → 引出观点 → 延伸到读者 | 个人经历、案例 |
| 热点-解读-预判 | 还原事件 → 独特解读 → 趋势预判 | 追热点（24h 内发） |
| 清单-深度-总结 | 全貌表格 → 逐项展开 → 行动清单 | 干货合集 |

提纲通用约束：第一行是**一句话中心**，每块能指回它；块与块是问答关系——上一节结尾抛出读者会问的问题
（「那怎么办？」「安全怎么保证？」），下一节答。小标题说明本节讲什么但不剧透结论，让读者能跳读。

## 正文手法与重点标记（第 6 步）

- **首句钩住**：首句的唯一任务是让人读第二句。用新鲜 / 悖论 / 反常事实 / 问题之一起手。
  🔴 **禁的是「知识性 / 教科书式背景交代」，不是一切铺垫。**
  「在当今 XX 时代」「下面我来介绍」「首先需要了解」不用 —— 毛病是**对谁都成立、不可核对**。
  **具体、能指认的场景或痛点可以做首句**，那是进入正题不是铺垫：
  > 「过去，我常用 md.doocs.org 这类工具，把 Markdown 粘进去渲染再复制到后台……流程繁琐且重复」
  > （jimmysong.io 已发布教程的首句）
  别堆陌生术语——「缓」只对这半句成立。
  📌 与红线一、第 3 步素材形态**同一条判据**：可核对 vs 对谁都成立。
- **半讲的故事**：开头四选一——叙事（讲变化的开端不讲结局）/ 研究（只放一小部分发现）/
  论断（下大胆判断先不解释）/ 提问。答案留给正文。
- **连到读者自己的问题**：钩子之后一句话把它接到读者此刻的处境上（多数开头败在这一步）。
  开头 150 字内兑现标题承诺的东西——后台「5% 处跳出率」量的就是这里。
- **结尾要硬**：事实讲完、观点立住就找最近的出口停；用一句有终结感的引语或意外细节收，**不总结全文**，
  **不使中心思想变形**。
- **衔接要净**：上一幕是上一幕，这一幕是这一幕。实在不行就用序号。
- **内容不够时不要扩写，去写细节**——但细节必须从素材单里取（红线一）。

句子级规则：

- 写到 13 岁能跟上逻辑：抽象词（格局 / 赛道 / 赋能）换成具体动作，每句一个想法，术语必配例子。
- 删修饰性小词（有点 / 非常 / 其实）和多数副词形容词；**保留表达确定度的限定**（「我认为」「多数情况下」），它们是信息。
- 名词优先实物名词，一句里两个以上抽象名词就重写；每个论断配一个可感知的细节或数字。
- 用「你」不用「大家」，想象一个具体的人坐对面，全文口语能说出口。
- 先讲故事，结论让读者自己得出；未知概念用类比搭到已知上。
- 段落 ≤ 4 句。

**重点标记按规范的两档来用**（第 1 步拉到的那份里写着确切规则）：
`**加粗**` 标「这句话是重点」，每段 1~3 处，整段加粗等于没标；
`*…*` 标「这几个字要被眼睛扫到」，比加粗轻一档。
🔴 在中文稿里 `*…*` **不是斜体**——汉字没有真正的斜体字形，渲染器把它接管成了关键词记号。

## 重写（第 7 步）

初稿允许烂，重写时间要多于初稿。顺序固定：

1. **口述摘要重写**：读完一节 → 歇一会 → 凭记忆只写关键点重写；记不住的部分就是读者也记不住的部分。
2. **朗读全文**：标出 (a) 读到打结的句子 → 改；(b) 自己不想读的段落 → 整段删。
3. **减法先大后小**：① 删与一句话中心无关的整段 ② 合并相近观点 / 同质案例 / 镜像重述
   ③ 逐句删「的 / 是 / 了」、代称、因果连接词、累赘词。
4. **不确定为真的句子删掉重来**，绝不放过（Morris 法则）；反复读到没有一处「刺挂住袖子」才交第 8 步。

## 结尾的行动号召（第 6 步）

**结尾的行动号召从档案里取**：`prep --json` 的 `products[].ctaScript`（每个产品各一条，
取匹配当前选题那个产品的）。背书 / 案例 / 内容资产**没有专属字段**：档案里叫什么取什么
（`persona`、`charter.positioning` / `charter.audience`、范文），没有就按红线一留【待补】，
**绝不自己编一个背书**。

不伤人设的写法：

- **一篇只要一次**，放在给足价值之后——每次 CTA 都在花读者的注意力余额，许可随时可撤回。
- 写成第一人称对一个人说：「如果你正卡在 X，这个能帮你的是 Y」；不写「限时抢购」「最后 N 名」。
- 用可验证的数字替代形容词；「国家级 / 最高级 / 最佳 / 第一」类极限词不进标题、摘要、正文。
- 带购买方式（链接 / 二维码 / 店名）的，文首显著标「广告」（第 9 步硬拦）。
- 「点在看 / 转发 / 关注才能看到…」的利益诱导或胁迫式互动不写；自然的一句「你怎么看，留言聊」可以。

## 摘要与留言（第 8 步）

两个最容易被忘的地方，流程化写作的价值就在这儿：

- **摘要**：订阅者在号内、分享到对话框都看得到，和标题同等重要——按「备用标题」写，别写成正文缩写。
  硬上限 120 字；留空时系统抓正文开头当摘要，抓到的多半是铺垫句，所以必须写。
- **留言**：作者给自己文章的第一条留言，既打破 0 留言的尴尬，更是**写作者对读者说的话**。
  写成邀请读者表达认同 / 讲自己经历的一句，不写「求关注」。
- **关注引导两道关**：开头下方一行「这个号给谁、写什么」（图文页内的名称卡片是 1 步关注），
  文末关注卡片 / 二维码（扫码关注发生在读完之后）。只有文末的号，转发进来的读者读完不知道你是谁。

## 提纲的小标题与定形状（第 5 步）

**第一行写一句话中心**（读者带走的那一个想法），指不回它的块删掉。
→ 四种结构见 `references/craft.md`，**选一种，别混着来**；块与块是问答关系（上一节末的问题下一节答）。

**小标题 = 论点，每个小标题下先列关键词 = 论据，并标注这一块用素材单里的哪几条**（编号）。
指不上素材的块回第 4 步补，或按红线一留占位。至少一块是读者能转述给别人的实用价值。

定形状：按规范「什么内容写成什么结构」标出哪块是有序列表 / 表格 / 引用块。

## 重写的四步减法（第 7 步）

初稿不直接交：① 凭记忆只写关键点**口述摘要重写** ② **朗读**，标出打结的句子，自己不想读的段落整段删
③ 减法先大后小：删无关整段 → 合并同质观点 → 逐句删累赘词 ④ **不确定为真的句子删掉重来**。细则见 `references/craft.md`。
