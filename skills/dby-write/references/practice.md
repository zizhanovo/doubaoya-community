# 练写作（普通人可照做的练习清单）

> 用户说「想练写作 / 怎么提高 / 帮我看看我的文章哪里差」时读它。写一篇 / 复盘一篇都不需要读。

唯一被多方印证的提升机制是**反馈闭环**：写 → 拿到具体反馈 → 改 → 再交。没有反馈的产出不算练习；频率本身不是方法。

1. **只问两件事要反馈**：把稿子给一个人看，只问「哪里看不懂 / 哪里拖」，另问「哪句话我最会后悔」。不问「好不好」。
2. **拆自己喜欢的文章**：标出最好和最差的段落，各写一句为什么；模仿你喜欢的作者写一段。
3. **AI 当老师，三轮问**：把最喜欢的一篇文章喂给模型，依次问「从写作角度分析 / 从读者角度分析 / 缺点与改进空间」；
   再把自己的稿喂进去用同样三轮，教师设定加一句「多举例少讲理论」。
4. **拆范文成 DNA**：收一位作者 10–20 篇爆款，每篇答五问（怎么开头 / 段落节奏 / 绝不用什么 / 金句长什么样放哪 / 情绪怎么起伏）；
   同一模式 ≥ 3 篇出现才算 DNA。这就是 `dby-charter` 蒸创作 DNA 的人肉版。
5. **一次只追一个指标**：这篇能让多小的读者跟上？还能删几个词？完读多高？朋友打几分？每篇只盯一个。
6. **名词圈色**：拿自己一篇旧文，实物名词一色、抽象名词一色；再圈别人文章里名词前的形容词——看见自己抽象名词的密度。
7. **先说再写**：动笔前把这个题跟一个人说一遍（或写成给朋友的消息），把说出来的话当初稿。
8. **随身选题池**：读到的惊讶点、聊天里说顺的句子、洗澡想法进笔记；卡片正面记例子，背面记「能用在哪」；专门收类比。
9. **抬高输入**：朋友圈 < 好文 < 好书 < 学术文献，只读非虚构，书单自己选。
10. **复盘只修一处**：走本包模式 B，四象限只给一处修复动作，改完再发再看。

不采：「日更 30 天必涨粉」（频率不是机制）、「每 300–500 字一金句」（小样本 AI 统计）、「AI 心理侧写作者」（娱乐）。
