# 标题：写法清单与常青判据（第 3 步）

> 第 3 步出候选前读它。五项自检表在 SKILL.md 第 3 步，这里是写法与「缺口看目标」的细则。

## 标题的几种写法

可组合的几种写法：关键词吸睛（对号入座 / 升维词 / 借势）、冲突反差、
提问式、悬念式、场景式、经验分享式、强调式。

写完按 SKILL.md 第 3 步五项过。**缺口那一项看本篇目标**——涨粉 / 变现才强制。

- **目标 = 涨粉 / 变现**：「天然正确、人人已知」的标题（《成长比工资重要》）不算缺口，
  要改成有认知落差的写法。
- **目标 = 常青**：平实描述就是这类的正解，别硬套缺口。
  真实范例：《开发将 Markdown 一键发布到微信公众号草稿工具的经验分享》（jimmysong.io，已发布）——
  零悬念零颠覆，读者靠「这正是我要找的东西」点进来，不靠好奇。
  谁都不会点的老实标题会卡在「完整陈述句」或「受众匹配」，那两项三种目标一视同仁。

⚠️ 想一遍**转发到朋友圈**：不好意思转的砍掉。

## 字数与截断的出处（SKILL.md 第 3 步表「完整陈述句」那行）

- 后台标题上限 **64 汉字**（调研 01，`docs/research/dby-write/01-wechat-hard-limits-2025.md`）。
- 列表页最多显示约 **31 字、含标点约 25 字**，之后被省略号盖掉；所以**核心信息放前 20 字**、关键词前置，
  壹伴的建议也是「20 字左右」（调研 02，`02-yiban-title-length.md`）。表里的「15–28 字」是这条与 BuzzSumo 样本（中文约 20–30 字）的交集。
- 长标题不是禁区：流量主要来自搜一搜的号可以写长，多塞几个读者会搜的词（同 02）——对应「搜索适配」那行。

## 标题党为什么在推荐流里吃亏（红线三的机制注脚）

推荐流按完读率等指标决定一篇文章能否从冷启动池晋级，**点击高、完读低**的文章会被判低质、拿不到下一级曝光——
标题承诺的东西正文不兑现，损失的不只是信任，还有推荐。只取「完读率参与分级」这个机制，
🔴 **不采其中任何百分比**：来源（调研 07，`07-jzl-2025-algorithm-completion-rate.md`）是数据工具商的营销稿，单案例、无样本量、正文夹带跳转链接，可信度有限。
