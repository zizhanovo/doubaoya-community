# 多平台文案改写 / wechat-rewrite

> 都爆鸭社区出品 · 纯本地工具 · 零网络调用 · 不需要 API Key

---

## 简介

把一份原文改写成**目标平台读者习惯的样子**，支持七个平台：
**公众号 / 视频号 / 抖音 / 快手 / B站 / 小红书 / 知乎**。

可以只改一个平台，也可以一次全出——那就是「一稿多发」：同一份原文，七个平台各出一版，
而不是一版群发七处。

> 📌 目录名比内容窄：本包由原来的公众号改写、小红书改写、多平台改写三个包合并而来，
> 沿用了 `wechat-rewrite` 这个目录名（它是站点详情页的挂钩）。记成命名债即可。

**核心价值**

- **一平台一套规则，不混用**：公众号要金句与钩子、标题 ≤20 字；小红书要至少 5 个不重复
  emoji 与种草口吻；知乎要论证感；抖音快手要短平快。七套规则各自成文，不是一套模板套七遍。
- **以作者视角输出**：用户的文案就是你的文案，只做风格转换，不说「帮你改写了」。
- **只改风格、不改事实**：产品参数、价格、功效照搬原文——改写是换说法，不是编新卖点。
- **交付即可用**：标题 + 正文 + 该平台习惯的标签 / emoji，拿过来就能发。

**适用对象**

- ✍️ **公众号号主 / 自媒体** —— 把素材快速改写成可发布的平台口吻文章
- 📣 **品牌与内容运营** —— 一份通稿铺到多个平台，各自说各自的话
- 🌱 **新号冷启动** —— 照着平台调性写，少走弯路

## 怎么用

装好之后直接跟你的 agent 说就行：

```
把这段文案改成小红书风格：这款面霜保湿效果很好，用了一周皮肤明显变水润了
```

```
这篇稿子帮我一稿多发，七个平台各出一版
```

agent 会去读对应平台的规则（`references/<平台>.md`）再动笔。
**没说平台它会问你一句**——七个平台调性差很远，猜错等于白改。

也可以自己把规则打出来看：

```bash
python3 scripts/rewrite.py list                  # 七个平台和它们的别名
python3 scripts/rewrite.py 小红书                 # 单平台规则
python3 scripts/rewrite.py 抖音,知乎 "原文…"       # 多平台（逗号或空格分隔都行）
python3 scripts/rewrite.py all                   # 全平台（一稿多发）
```

平台别名：`公众号/微信公众号`、`视频号/微信视频号`、`抖音/dy`、`快手/ks`、
`哔站/B站/bilibili/哔哩哔哩`、`小红书/红书/xhs`、`知乎/zhihu`。

## 目录结构

```
wechat-rewrite/
├── SKILL.md              # 给 agent 看的入口 + 按平台分流
├── README.md             # 本文件
├── references/           # 平台规则，一平台一文件（脚本与 agent 读的是同一份）
│   ├── 公众号.md   ├── 视频号.md   ├── 抖音.md   ├── 快手.md
│   ├── B站.md      ├── 小红书.md   └── 知乎.md
└── scripts/
    └── rewrite.py        # 平台别名解析 + 取规则（纯标准库，零网络调用）
```

## 前置条件

- Python 3（脚本仅用标准库，不装任何第三方包）
- 不需要 `DOUBAOYA_API_KEY`，不联网

> ⚠️ 都爆鸭平台上另有一条**同名的云端能力** `skill.wechat.rewrite`（计费）。
> 它和本包不是一回事：本包装在你机器上、就地改写、不花钱。详见 SKILL.md 里的说明。
