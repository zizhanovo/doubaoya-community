# 诊断：死法清单 · 三层脱节 · 商业四检 · 消解坏问题

这个文件在两种时候读：**做体检**（老号反推、章程回顾）和**用户卡壳**（答不出、绕圈、越说越虚）。

用法上有一条总纪律：**诊断是支线，不是关卡**。本文所有检查都以**软性追问 / 预警**的形式吸收进对话——
谈不清就在对应字段尾部标注「（待深化）」继续走，**不做硬阻断闸**。教练的失败不是「让用户带着待深化的字段离开」，
而是「把用户卡在一个问题上耗到他不想聊了」。

---

## 第一节 · 死法清单（六种）

自媒体号的死法高度重复。你不需要等用户描述完全部背景——听到症状就能定位切入点。

### 1. 停更（头号死因）

- **识别症状**：更新从日更掉到周更再到月更；用户提起账号时用过去时；「最近太忙了」出现两次以上。
- **根因不是没时间**。真实链条是：三层脱节 → **变现无门** → 兴趣索然 → 停更。
  用户以为自己缺时间，实际上是这件事已经在他的优先级里排不上号了——因为它不产出任何回报。
- **切入点**：**先谈钱**。问诊直奔 `monetization`，别先陪他讨论「怎么坚持」。
  「你之前更了多久？那段时间这个号给你带来过什么？」——把话题引到回报缺口上。

### 2. 定位模糊

- **识别症状**：什么都写（今天职场明天美食）；让他一句话说清这个号是干嘛的，他要说三句以上；
  问「你的读者会怎么向别人介绍你」，答不上来。
- **切入点**：**三级火箭切割 + 一句话记忆点**。走 `frameworks.md` 第 4 节，
  从大领域一路逼到「某类人的某个时刻」；切完立刻回到第 4 问，让他用一句话说出来。

### 3. 频繁改号

- **识别症状**：改名改赛道成瘾，一年换三个方向；每次都说「上一个方向不行」；账号简介改过很多版。
- **危险处**：改号本身会重置读者认知，改得越勤账号越像新号。而且**改号常常是在逃避真正的问题**——
  不是方向错了，是变现没接上或者根本没更够量。
- **切入点**：**复盘既往死因**（问诊第 14 问）。「上一个方向你做了多久、更了多少篇、为什么停？」
  连续问两版，用户自己就会看到重复的模式。

### 4. 节奏不稳

- **识别症状**：爆更三天、停更三周；「有灵感就写」；发文时间散乱无规律。
- **根因**：选题依赖灵感，而灵感依赖状态。可持续的节奏来自**选题有来源**（定位 + 读者提问池），
  不是来自自律。另一半根因是选了自己撑不住的赛道。
- **切入点**：**兴趣持久性**（问诊第 2 问）。「这个方向，不给钱你还愿意写一年吗？」
  答犹豫，说明第 2 个圆有问题，回三叶草。

### 5. 只涨粉不变现

- **识别症状**：能清楚报出粉丝数和阅读量，问到收入就含糊；把「涨粉」当成目标本身；
  在追与自己变现路径无关的热点。
- **根因**：**流量思维替代了产品思维**——默认「粉丝多了自然有人买」。
  实际情况是粉丝多但产品体系空的号，流量全部浪费掉。
- **切入点**：**北极星四选一**（问诊第 13 问）。逼他在 `read` / `follower_growth` /
  `private_leads` / `gmv_repurchase` 里选一个并说出理由。
  选完追一句：「那接下来三个月，涨粉数据掉了但私域线索涨了，你算成功还是失败？」

### 6. 受众不清

- **识别症状**：说读者是「所有想进步的人」「二三十岁的年轻人」；
  描述读者时只有人口属性没有处境；说不出读者在什么场景下会打开。
- **一句话**：**写给「所有人」= 写给没有人**。
- **切入点**：**受众画像与决策场景**（问诊第 5 问）。
  「上一次有人当面向你请教，那个人多大、什么身份、当时卡在什么事上？」
  用真实的一个人替换掉抽象人群，比任何画像模板都快。

## 第二节 · 三层脱节诊断法

**做法**：让用户**分别陈述**三层定位，一层一句，写下来放在一起：

| 层 | 提问 |
|---|---|
| **内容定位** | 「这个号主要写什么？」 |
| **用户定位** | 「这些内容主要吸引来的是什么人？」（注意问「实际吸引来的」，不是「想吸引的」） |
| **商业定位** | 「钱最终从谁身上、通过什么方式进来？」 |

**然后做两次咬合校验**（当着用户的面做，让他自己看见接缝）：

1. **写的内容吸引来的人，是不是会付费的人？**
   脱节样例：内容是「打工人吐槽 + 情绪共鸣」，吸引来的是同为打工人的共情读者，
   产品却是面向企业 HR 的培训——**共情读者不是预算持有人**。
   修法二选一：换内容（转向 HR 关心的议题），或换产品（做面向打工人的低客单产品）。

2. **付费路径和内容主题是否互相加持？**
   脱节样例：内容是完整的免费干货合集，产品是同一批干货的付费整理版——
   内容在**替代**产品，不是在**引向**产品。
   加持的结构是：内容让人意识到「这事我自己搞不定 / 我搞错了方向」，产品接住这个缺口。

**特例：使用者 ≠ 付费者。** 有些赛道天然是分离的——孩子看、家长付费；员工用、老板买单；
病人受益、子女下单。这不是脱节，但**必须显式记下来**，否则内容会写给错的那一方。
把它写进 **`audience.payerNote`**（如「内容给 25-30 岁职场女性看，付费的常是她们的伴侣/父母」）；
两者一致时留空串。

**诊断结论怎么给**：脱节处直接说出来，但**只说事实、不马上给方案**（红线 5：克制给结论）。
「你写的内容吸引的是 A，你想收钱的是 B——这两个不是同一批人。你觉得该动哪一头？」
让用户自己选往哪个方向修。

## 第三节 · 商业诊断四检（软性追问，不做闸）

四检是**入口体检**——在谈内容之前，先确认这门生意的底层假设成不成立。
坏的商业模式**越往下走、盖得越完整，倒得越惨**。

但请严格按软性形式吸收：**每检问 1–2 句，谈不清就在对应字段尾部标「（待深化）」继续走**。
不要把四检做成必须全绿才能继续的关卡，那会把问诊变成审讯。

### 印钞机检 —— 投入 / 产出 / 可替代性

「你投入什么、产出什么、这个产出别人能不能轻易替代？」

**可替代 = 没有印钞机。** 如果同赛道任何一个人花两周都能产出同样的东西，那这个号赚的不是钱，是时间的零工费。
不可替代的来源通常是三种：真实经历、独家数据 / 案例、长期积累的判断力——而**不是**「我写得比较用心」。

→ 谈出来的内容喂 `positioning.tag` 与 `northStar.rationale`；谈不清标「（待深化）」。

### 定价检 —— 定价即产品

「你打算靠**哪个价位**赚钱？」

先想清价位，再想内容。**引流款与利润款可以差 10 倍**（9.9 的入门课与 999 的陪跑是两个产品，不是同一个的折扣）。
而且**价格本身就是定位信号**——收费偏低会被市场直接归类成入门型服务者，且低价客群的服务成本往往更高。

→ 喂 `monetization.path` 的选档判断与 `gapNote`。

### 需求检 —— 显性购买 ≠ 隐性使用

「用户嘴上说要的，和真正会掏钱买的，是同一件事吗？」

这两者经常两回事：人们说想要「系统的知识」，付费买的却是「立刻能用的模板」；
说想「提升自己」，实际买单的是「明天开会能用上的话术」。
**要押的是有人真会付款的显性需求**，不是被广泛使用但没人愿意付费的需求。

判据只有一个：**这件事，有人已经在为它付钱了吗？付给谁？付多少？** 有人在付钱是最强的需求验证。

→ 喂 `audience.persona`（把画像收到「会付钱的那一小撮」）与 `monetization.practicalPaths`。

### 规模化检 —— 能不能沉淀出可复制的做法

「这条变现路径，能沉淀出一套可复制的做法，还是永远锁死在你的时间上？」

一对一咨询是典型的「锁死在时间上」——收入 = 小时数 × 单价，天花板是硬的。
不是说不能做（它常常是最好的起步现金流），而是**要知道自己在哪一档**，
并且知道下一步往哪走（一对一 → 小班 → 课程 → 社群）。

→ 喂 `monetization.stage`（`startup` / `accumulation` / `monetization`）与 `review.nextTrigger`。

## 第四节 · 消解坏问题（教练卡壳时的支线）

用户绕圈、你也问不下去的时候，往往不是答案难，是**问题本身坏掉了**。先把问题问对，再谈答案。

### ① 错问题——方向问反了，先掉头

有些问题无论怎么答都到不了目的地。典型：「怎么才能涨粉快？」——
用户真正想解决的是「怎么赚到钱」，涨粉只是他以为的手段。硬答涨粉，会把他推进「只涨粉不变现」那个死法。

**做法**：不答，先掉头。「我们先确认一下——你想要的是粉丝数，还是收入？如果是收入，
这两件事的打法不一样，甚至可能相反。」

### ② 未定义词——先定义再问

「适合 / 值得 / 赛道 / 有价值 / 做好」这类词没有定义就无法回答，用户和你各自脑补一套。
典型：「这个赛道适合我吗？」——「适合」是什么意思？赚钱多？做起来不累？有成就感？三个答案通向三个方向。

**做法**：定义再问。「你说的『适合』，是指赚得多，还是指你能长期做下去不烦？
如果两个都要，我们先看哪个是硬约束。」

也顺带提醒一句：**「适合我」本身常常是伪问题**——真正决定成败的是有没有人付钱，不是舒不舒服。

### ③ 相关当因果——「一起出现」≠「因为所以」

「那个号发日更所以做起来了」「他们都在做视频所以我也要做」——
把同时出现的两件事当成因果，是最常见的误判来源。同赛道跑出来的号身上有几十个变量，
用户只看到了最显眼的那一个。

**做法**：拆开问。「他日更之前，是不是已经在这行做了十年？
如果是，可能起作用的是那十年，不是日更的频率。」

## 收尾提醒

- 诊断的产出是**追问方向**，不是结论清单。信息收敛前不要抛判断（红线 5）。
- 任何一处谈不下去：**原样记下用户的现状 + 尾部标「（待深化）」+ 往下走**（红线 4）。
  下次会话开场读基线时，这些标记就是续问点。
- 诊断里出现的任何数字（门槛、单价）都来自 `monetization.md`，是 **2026-08 快照**，引用必须说明会过时。
- **不承诺效果、不编造数据**——诊断只提高命中概率，不保证结果。
