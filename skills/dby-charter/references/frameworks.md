# 定位框架（教练用）

> **立场声明**：下面这批框架在市面上是**多版本同构**——各家培训讲的都是同一批变体，换个名字、换个圈数，
> 内核没变，也**没有公认的原创出处**。所以本文**不强行归因原创者**，只讲「它在说什么」「教练怎么用它」。
> 你在对话里也别把框架当权威背书抬出来（「某某老师说」），把它当成**逼具体的提问脚手架**用。

框架的唯一用途：**当用户答不出来的时候，给你下一个更小的问题**。用户不需要听你复述模型，
用户需要的是被问到具体处。讲框架 ≤ 3 句，剩下的时间全用来问。

---

## 1. 三叶草模型：能力 × 兴趣 × 需求

三个圆的交集才是可持续的定位：**你会的**（能力，别人认可你干得好的事）、**你能持续做的**
（兴趣，一年内不会厌倦、能稳定输出上百条内容的事）、**市场要的**（需求，有人真的在找答案且现在解得不好）。
同构变体到处都是——「三圈模型：你会的 × 市场要的 × 你能持续做的」是最常见的一版，说的是同一件事。

**为什么必须是交集**：只有能力 × 需求，缺兴趣 → 写三个月就厌了，这是停更的标准起点；
只有能力 × 兴趣，缺需求 → 自嗨，发出去没人接；只有兴趣 × 需求，缺能力 → 写不出别人写不出的东西，
拼不过同赛道。三缺一都不是定位，是爱好或是苦役。

**教练用法**：问诊第 1–3 问（能力盘点 / 兴趣持久性 / 需求验证）就是在**替用户画这三个圆**。
用户回答完这三问，你手里应该已经有三张清单；交集为空是一个真结论——那就得往回退，
问「哪个圆可以换一换」，而不是硬编一个交集出来。

## 2. 人设标签矩阵：专业 / 爱好 / 性格 / 缺陷 / 优势 / 服务人群

拿一张纸，把六类标签列出来：**专业标签**（你靠什么吃饭）、**爱好标签**（你不上班时在干嘛）、
**性格标签**（别人形容你的形容词）、**缺陷标签**（你身上真实的不完美）、**优势标签**（你的资源与稀缺处）、
**服务人群标签**（你身边一直在向你请教的是哪种人）。

**关键一句**：只有专业标签，人设是一个「**面**」；加上爱好、性格、缺陷，才立成一个「**体**」。
面很薄，随时可以被替换；体才有辨识度。而在 AI 时代这句话变得更硬——**干货会被 AI 复制，人格不会**。
纯信息型的账号正在被批量生产，能留下的是「这个人怎么想、怎么活、栽过什么跟头」。

**缺陷标签最被低估**：用户往往下意识只填正面的。缺陷不是自曝短板，是**活人感的来源**——
「我也是三十岁才转行的」「我数学一直很差」这类标签让读者敢开口问你问题。

**教练用法**：第 7 问（专业权威 vs 真实温度取向）就是在给这个矩阵定调门。矩阵的产出喂给
`positioning.oneLiner` 与 `positioning.tag` 的**口吻**——同一个专业定位，权威调门和温度调门写出来
是两个完全不同的 tag。

## 3. 七步全景：造赛道 → 找定位 → 贴平台 → 定产品 → 挑渠道 → 调运营 → 搭团队

流传较广的一版全景框架（常被叫作「7P」）把做号拆成七步：**造赛道**（在哪个大盘里玩）→
**找定位**（在赛道里占哪一格）→ **贴平台**（这一格在哪个平台上最吃香）→ **定产品**（卖什么）→
**挑渠道**（人从哪来）→ **调运营**（节奏与打法）→ **搭团队**（谁来干）。

**教练只用前四步**。后三步（渠道 / 运营 / 团队）是执行层，用户连卖什么都没想清就聊团队，
是典型的把力气花在最后一公里。号章程覆盖的正是前四步：赛道与定位落到 `positioning`，
平台与产品落到 `monetization`。

**教练用法**：用户问「我是不是该同时做小红书和视频号」「要不要找个剪辑」这类问题时，
用这个框架**把他拉回前四步**：「这些是第 3 到第 7 步的事，我们先把第 2 步定下来——
定位定了，平台和产品自己会浮出来。」

## 4. 三级火箭切割：大领域 → 细分赛道 → 专业标签

定位落地的执行动作是**逐级收窄**，而且直接映射号章程的三个字段：

| 级 | 问题 | 字段 |
|---|---|---|
| 大领域 | 你在哪个大盘里？ | `positioning.domain` |
| 细分赛道 | 这个大盘里的哪一小撮人？ | `positioning.niche` |
| 专业标签 | 他们在什么时刻、什么问题上认你？ | `positioning.tag` |

**粒度示例**（这是最好用的一个教学案例，直接念给用户听）：

> 「我想做职场号」 →（谁的职场？）「体制内的职场」 →（体制内的哪个坎？）
> 「体制内 30 岁科员的**晋升答辩**」

三级切完，`domain`=职场、`niche`=体制内职场、`tag`=体制内晋升答辩教练。注意最后一级已经具体到
**一个时刻**（答辩前那一周）——切到「时刻」才算切到位，只切到「人群」还差一刀。

**别怕窄**：0.1 还能切成 0.01。用户最常见的抗拒是「切这么窄没人看」——真实情况反过来：
宽定位的号在算法里谁也不像，窄定位的号一出现读者就知道该不该关注。窄不是放弃市场，
是**放弃跟你没关系的市场**。

**教练用法**：第 6 问就是这一刀。切不到「时刻」这一级时，用追问技巧库里的句式往下逼
（见 `intake.md` 第二节），两次逼不出来就在 `tag` 尾部标「（待深化）」继续走。

## 5. 三层定位自洽检查：内容 / 用户 / 商业互相咬合

三层定位——**内容定位**（写什么）、**用户定位**（给谁看）、**商业定位**（怎么赚钱）——单独看每层都可能很漂亮，
出事全出在**接缝**上。两两校验只有两个问题，但这两个问题能杀掉一大半看似完整的定位：

1. **写的内容吸引来的人，是不是会付费的人？**（内容 ↔ 用户 ↔ 商业）
   典型脱节：写「打工人吐槽」吸引来的是同为打工人的共情读者，卖的却是 5000 元的企业培训——
   共情读者不是预算持有人。
2. **付费路径和内容主题是否互相加持？**（内容 ↔ 商业）
   典型脱节：内容全是免费干货合集，产品是同一批干货的付费版——内容在**替代**产品，不是在**引向**产品。
   加持的写法是：内容负责让人意识到「这事我自己搞不定」，产品负责接住。

**这条检查是本 skill 存在的理由**。自媒体头号死因是**停更**，而停更的根因链条几乎总是同一条：
三层脱节 → 变现无门 → 兴趣索然 → 停更。用户以为自己是「没时间」，其实是这条链条走到了终点。
所以教练不是在帮用户「想个好定位」，是在帮他**把这条链条掐断在第一环**。

**教练用法**：信息收敛之后（不是每一轮），把三层各自复述一遍，当着用户的面做这两次咬合校验。
脱节处直接说出来，别绕。详细诊法见 `diagnosis.md` 第二节。

## 6. 多源研究共识（两条教练操作纪律）

以下两条不是框架，是从大量公开方法论里反复出现的共识，**写成你的操作纪律**。

### 纪律一：商业定位宜尽早锚定

行业共识的顺序是 **先商业 → 再人设 → 最后内容**：商业定位决定内容该产什么、人设该立成什么样，
反过来推不成立。而**变现后置**是公开材料里被点名最多的常见错误——人设定妥、名字头像都做好了，
内容跑起来才发现变现路径接不上，只能推倒重来。

**落到操作**：教练**对话顺序可以灵活**（用户想先聊人设就先聊，硬按顺序问会把人问跑），
但你心里的账不能乱——**不得让用户把人设定妥了才发现变现路径接不上**。
只要人设已经开始收敛而 `monetization.path` 还空着，就该主动把话头拐到钱上：
「先插一句钱的事，免得我们后面白做——这个号你打算怎么赚钱？」

### 纪律二：定位是持续校准的，不是一次问诊定终身

公开材料里反复出现的一句话是：**定位是解决 100 个问题之后长出来的**。它描述的是同一个过程——
先喊出一版定位（自己觉得挺准）→ 投入市场发现读者其实不这么看（假定位）→ 靠真实读者的提问一次次修正
→ 定位才真正立住。

**落到操作**：① 收尾时明确告诉用户「这版章程是**第一版**，不是终版」；
② 引导用户**记录真实读者提问**（谁问的、问了什么、为什么问）——这是校准定位最便宜的原料；
③ 把校准触发条件写进 `review.nextTrigger`（如「粉丝过 100 达流量主门槛时」「收到 20 条读者提问时」），
`review.lastReviewedAt` 记下这次问诊的日期。

**章程的 `review` 节存在的理由就是这条纪律**。没有 `review`，章程就退化成又一份存盘即死的报告。
